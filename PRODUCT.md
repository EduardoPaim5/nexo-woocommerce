# Nexo
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
WordPress, WooCommerce, PHP, MySQL and Docker Compose. User explicitly requested WordPress and WooCommerce for a junior developer portfolio.
## Users
Recruiters inspect the implementation; shoppers in the demonstration browse desk and audio accessories, choose variations, add to cart and place a simulated order.
## Product Purpose
Demonstrate functional WordPress customization and PHP extension development. No real business, sales, payment collection or customer endorsements.
## Capabilities and Constraints
Responsive storefront, real WooCommerce catalogue/cart/classic checkout, variable products, stock, coupon, configurable shipping rule plugin and tests. Local preview first: Sites hosting does not run PHP/MySQL. Public hosting remains a separate operation.
## Assumptions
Nexo is a fictional brand selected for this demonstration. Catalogue specifications, prices and availability are illustrative. No external customer data is used.
