# Imagens e proveniência

## Coleção de produtos

Os oito arquivos `assets/*.webp` são imagens conceituais geradas com a ferramenta integrada imagegen para este projeto. A capa `theme/assets/hero.jpg` deriva da mesma imagem do headphone, com otimização de tamanho. Não são fotos de produtos reais; não representam fabricantes ou itens disponíveis para compra.
